# Generator
Функционал:
1. Рандомайзер цифр
2. Генератор ру имён
3. Генератор фамилий
4. Генератор личностей
5. Рандомайзер от 1 до 10
6. Генератор банк. карт
7. Генератор паролей
8. Генератор ссылок
9. Генератор ников
10. Генератор почт
11. Генератор тел.номеров
12. Генератор улиц
13. Генератор городов
14. Генератор профессий
15. Генератор анекдотов
16. ChatGPT 
17. Генератор QR-кодов

-------------------
main.py - основной файл
banner.py - интерфейс программы
person.py - база данных
-------------------

Установка/Запуск ( Termux )

**pkg install python**

**pip install faker**

**pip install colorama**

**pip install g4f**

**pip install segno**

**git clone https://github.com/marjaway/Generator**

**cd Generator**

**python main.py**
